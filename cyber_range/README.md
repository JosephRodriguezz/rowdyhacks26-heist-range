# Lab implementation boundary

Build one storefront/API with two lab users, separate private orders, one seeded ownership flaw, and one protected control endpoint. Emit structured request logs and expose a deterministic reset command.

Store seeded vulnerability ground truth outside team-visible application routes and contexts. Keep any model-provider egress outside the isolated target/tool execution boundary.

Use disposable target copies for patching and record exact versions in retest results. No vulnerable application or network configuration is implemented yet.
