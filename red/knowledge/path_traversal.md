# Path traversal in document selectors

A download operation may resolve user-controlled document names outside its intended document root. Observe a valid download and available document references first. Compare a permitted name with a bounded selector whose normalization would leave that root. Keep the route, input category, returned document identity, and data effect as evidence. A missing-file error does not prove traversal succeeded.

For defense, validate the resolved resource against its permitted root or an explicit document allowlist and preserve legitimate downloads. This lesson applies only to the assigned lab's document operation. See [OWASP Path Traversal](https://community.owasp.org/attacks/Path_Traversal).
